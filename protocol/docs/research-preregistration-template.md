# Preregister an experiment

Fill this template before collecting outcomes. Use the types in [`researchExperimentSchemas.ts`](../src/api/researchExperimentSchemas.ts) and freeze the result with the [record workflow](research-experiments.md). The synthetic JSON fixtures show the machine-readable shape, not a ready-to-run scientific design.

## Freeze sampling and analysis

For a pilot, record the feasibility/variance rule and the intended later decision.

For a confirmatory comparison, record the pilot reference, sample-size rule, independent-unit target and lock time before confirmatory outcomes. Identify the analysis, evaluator, uncertainty and missing-outcomes artifacts by version and digest. Separate confirmatory evidence from exploratory observations and later repairs.

## Define the resource ledger

For generation, coordination, failed attempts, review, retrieval, proof, storage and human work, identify the measurement source and authoritative economic-fact identity. Name inherited knowledge-production facts, shared overhead, unavailable quantities and cash valuation limits.

Keep observed external expense, estimates, internal transfers and subsidies separate. Record unknown obligations rather than zero. Define the meaning of the eligible-scheduled-attempt denominator before reporting amortized cost.
